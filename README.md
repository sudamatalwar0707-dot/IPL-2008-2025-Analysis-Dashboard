# IPL-2008-2025-Analysis-Dashboard
📊 IPL Analysis Dashboard (2008–2025)
Project Overview

  The IPL Analysis Dashboard (2008–2025) is an advanced interactive Power BI project that delivers comprehensive insights into the Indian Premier League across all seasons from 2008 to 2025. The dashboard is designed with a dynamic season slicer that allows users to analyze any IPL season with a single click, instantly updating all visuals, KPIs, player profiles, team names, and logos across the report.
  This project demonstrates strong expertise in data modeling, DAX calculations, dynamic image handling, and interactive dashboard design, making it a high-impact business intelligence and sports analytics solution.

Key Features & Functionality
🔹 Dynamic Season Slicer (Core Feature)

A season slicer enables users to switch between IPL seasons (2008–2025)
On selecting any season:
Champions & Runner-Up teams update automatically
Points table recalculates dynamically
Player statistics refresh instantly
Team logos, player images, and team names change dynamically using DAX
Entire dashboard responds in real time with one click, ensuring a seamless analytical experience

Dashboard Highlights
📌 Tournament KPIs (DAX-Driven)

Matches Played
Total Teams
Total 4s & 6s
Total Centuries
All KPIs are calculated using custom DAX measures that respond dynamically to slicer selections.

🏆 Season Outcome Analysis

Champions and Runner-Up teams displayed with dynamic logos and team names
Outcome cards fully driven by slicer-based DAX logic

🧢 Player Performance Analysis

Orange Cap: Highest run scorer (dynamic player image, name, team)
Purple Cap: Highest wicket taker (dynamic player image, name, team)
Top 4s & Top 6s:
Player profile images change automatically
Statistics recalculated per selected season

📊 Points Table Analysis

Matches Played, Wins, Losses, No Results
League standings dynamically sorted by points
Fully synchronized with season slicer selection
DAX & Data Modeling Highlights
Season-based filtering using disconnected slicer logic

Dynamic measures for:

Top-performing players
Team rankings
Orange / Purple Cap holders
Dynamic image rendering using image URLs controlled by DAX
Optimized star-schema data model for performance and scalability

Tools & Technologies
Power BI – Dashboard development & interactivity
DAX – Dynamic KPIs, ranking logic, and image switching
Data Modeling – Fact & dimension tables
Excel / CSV – Data cleaning and preprocessing
